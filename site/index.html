A fast Git client that keeps your work safe.

NiceGit puts your repositories, branches, history and changes in one window, on macOS, Windows and Linux. Free and open source, with no account and nothing sent anywhere except by Git itself.

Download NiceGit View the source

For macOS 11+, Windows 10+ and Linux (x86_64). Git must be installed.

See your history

A commit graph with stable lanes and colours, branch and tag labels, and your uncommitted work joined to the commit it builds on. Search every branch by message, author, code change or commit ID, blame any file, and follow a file's history across renames.

  • Show every branch, only local ones, or just the current branch
  • Compare any two commits, side by side or in one column
  • Find the commit that introduced a bug with guided bisect

Stage exactly what you mean

Stage and unstage whole files or single lines. Hover a change in a diff to stage, unstage or discard just that change, and step through every changed file without leaving the diff. Edit working files in place when a quick fix is all you need.

  • Side-by-side or unified diffs, with word-level highlights
  • Unstaged and staged files in their own lists, always in view
  • A separate commit draft for each checkout

Rewrite history with confidence

Interactive rebase lets you drag commits into order, and pick, reword, edit, squash, fix up or drop them. Merge, rebase, cherry-pick, revert and reset, with a preview of which files will conflict before you start, and a built-in editor to resolve the conflicts that do.

  • Fold staged changes into an older commit with Fix up
  • Edit the message of any commit on the branch
  • Worktrees, submodules, stashes, GitFlow and Git LFS

Made for the keyboard

A command palette for actions, branches and repositories, an embedded terminal for each checkout, and every shortcut in one list. NiceGit refreshes when files change in other apps and fetches in the background, so what you see is current.

  • Light and dark appearance, and a colour-blind safe graph palette
  • Pull requests and issues through your existing GitHub CLI login
  • Make everything larger or smaller to suit your screen

Built so mistakes can be undone

Git is powerful, and NiceGit treats that power with care.

Undo

Undo the last commit, merge, rebase, reset, pull, cherry-pick or branch deletion, and bring back a file's discarded changes.

Checks before it acts

Every destructive action confirms that the branch, commit or remote you saw is still the one it will change, and refuses if it is not.

Safer force push

Force push with a lease: the confirmation lists what the remote would lose, and the push is refused if someone else pushed since your last fetch.

Recover lost work

Commits left behind by a reset or rebase can be found again from Repository › Recover Lost Work.

Download

Free, with no account, subscription or paid tier. Get the latest build for your system.

macOS 11 or newer · Apple Silicon and Intel .dmg Windows 10 or newer · 64-bit .zip Linux Debian and Ubuntu, or any x86_64 .deb · .tar.gz

Every version needs Git installed and on your PATH.

Or build it from source

Install Rust 1.95 or newer, then:

git clone https://github.com/daniaalnadir/NiceGit.git
cd NiceGit/rust
cargo run --release

On Linux, first install the GTK 3, xkbcommon and Wayland or X11 development packages, for example libgtk-3-dev libxkbcommon-dev libwayland-dev.
